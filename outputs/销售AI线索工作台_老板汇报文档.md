# 销售 AI 线索工作台项目汇报文档

日期：2026 年 6 月 23 日  
项目名称：销售 AI 线索工作台  
当前阶段：本地 MVP 已跑通，进入产品化迭代阶段

---

## 一、项目一句话说明

本项目是一个面向销售团队的 AI 线索工作台，可以把销售手机中的微信长截图、通话录音、客户资料自动同步到电脑端，由系统自动完成文字识别、录音转写、客户意向判断、客户归档和跟进建议生成，帮助销售和管理层更快发现高意向客户，减少人工翻聊天记录和漏跟进的问题。

简单理解：

```text
销售截图 / 录音
  -> 自动同步到电脑
  -> AI 识别文字 / 转写录音
  -> DeepSeek 分析购买意向
  -> 自动生成客户档案和跟进建议
  -> 老板和销售在工作台查看优先跟进客户
```

---

## 二、为什么要做这个系统

当前销售跟进中常见的问题：

1. 客户聊天记录分散在销售个人微信里，管理层很难实时了解客户质量。
2. 销售每天产生大量截图、语音、电话录音，人工整理成本高。
3. 高意向客户容易被埋在聊天记录里，销售跟进不及时。
4. 老板想看线索质量、跟进进度、客户意向，但缺少统一看板。
5. 新销售对客户判断能力不稳定，需要系统给出跟进建议和话术。

本系统解决的核心问题：

1. 自动采集销售资料。
2. 自动识别客户聊天和录音内容。
3. 自动判断客户购买意向。
4. 自动沉淀客户档案。
5. 自动生成下一步跟进建议。
6. 给老板提供可查看、可管理、可追踪的销售线索看板。

### 2. 后端系统

后端基于 FastAPI 实现，已包含：

- 登录认证
- JWT 权限控制
- 管理员账号
- 销售账号管理
- 客户管理
- 上传资料管理
- AI 分析结果管理
- 跟进记录管理
- 通话录音上传接口
- 看板统计接口
- 高意向线索接口
- 今日优先跟进接口

### 3. 微信长截图识别

已实现微信长截图自动进入系统的能力。

流程：

```text
销售手机截微信长图
  -> 手机 Syncthing 自动同步截图文件夹
  -> 电脑 Syncthing 接收图片
  -> 实时 watcher 检测新图片
  -> 自动上传到后端
  -> DashScope / Qwen-VL 识别图片文字
  -> DeepSeek 分析客户意向
  -> 生成客户档案和跟进任务
```

支持图片类型：

- JPG
- JPEG
- PNG
- WebP
- BMP

### 4. 通话录音同步与识别

已实现手机录音同步基础链路。

当前流程：

```text
手机录音文件
  -> Syncthing 同步到电脑
  -> watcher 检测新录音
  -> 自动上传后端
  -> Docker FunASR 本地转写
  -> DeepSeek 分析客户意向
```

当前已配置：

- Syncthing 手机录音同步
- 实时目录监听
- Docker FunASR 本地转写
- 录音原文件播放
- 录音上传记录
- 转写结果进入 AI 分析

### 5. DeepSeek 销售意向分析

已接入 DeepSeek API。

系统会根据客户资料输出：

- 客户姓名
- 客户电话
- 客户地址
- 客户需求
- 客户疑问
- 客户异议
- 关注产品
- 预算
- 购买时间
- 意向等级
- 意向分数
- 判断理由
- 关键证据
- 下一步建议
- 推荐销售话术

意向等级包括：

- 高意向
- 中意向
- 低意向
- 暂无意向
- 无法判断

### 6. 自动跟进任务

已新增“今日优先跟进”能力。

AI 分析完成后，系统会自动生成跟进任务：

- 高意向：建议 2 小时内跟进
- 中意向：建议次日跟进
- 低意向：建议 3 天后跟进
- 无法判断：建议补充聊天截图或录音

老板和销售打开首页即可看到：

- 哪些客户今天要先跟
- 为什么要跟
- 跟进优先级
- AI 给出的下一步建议

### 7. 原始资料预览

系统支持在客户详情中直接查看原始资料：

- 微信截图原图预览
- 录音原文件播放
- 上传资料历史记录
- AI 分析记录
- 自动跟进记录

这样方便管理层复核 AI 判断是否合理。

### 8. 测试数据与本地联调

当前已准备：

- 图片测试数据
- 录音测试数据
- 文本测试数据
- 后端自动化测试
- 手机截图 Syncthing 联调
- 后端、前端、watcher 本地全流程验证

当前已跑通的真实链路：


## 四、系统怎么使用

### 1. 管理员使用流程

管理员打开系统后，可以：

1. 登录后台。
2. 查看首页线索雷达。
3. 查看今日优先跟进客户。
4. 查看高意向客户列表。
5. 查看所有上传资料和 AI 分析结果。
6. 查看客户详情和历史资料。
7. 创建销售账号。
8. 检查 DeepSeek、OCR、ASR 配置是否正常。

默认本地测试账号：

```text
账号：admin
密码：admin123
```

正式使用前必须修改默认密码。

### 2. 销售使用流程

销售日常只需要做三件事：

1. 正常和客户微信聊天。
2. 对关键客户聊天记录做微信长截图。
3. 正常拨打电话并保留通话录音。

系统会自动处理：

- 截图自动同步
- 录音自动同步
- 自动上传
- 自动识别
- 自动分析
- 自动归档
- 自动生成跟进建议

销售只需要打开工作台查看：

- 今天要先跟谁
- 客户需求是什么
- 客户异议是什么
- 下一步该怎么说

### 3. 手机端配置流程

手机端通过 Syncthing 配置自动同步。

建议同步的手机目录：

```text
内部存储/Pictures/Screenshots
```

或：

```text
内部存储/DCIM/Screenshots
```

电脑端接收目录：

```text
work/Automatic-Phone-Recording-main/data/inbox/wechat
```

配置原则：

- 手机端作为发送方
- 电脑端作为仅接收
- 文件夹 ID 必须一致
- 不要删除本地数据
- 同步完成后 watcher 会自动处理

### 4. 电脑端启动流程

本地测试时，打开项目目录，双击：

```text
启动实时销售AI系统.bat
```

它会启动：

- 后端服务
- 前端页面
- Syncthing
- 实时 watcher
- Docker FunASR 相关环境

前端访问地址：

```text
http://127.0.0.1:5173/
```

后端接口地址：

```text
http://127.0.0.1:8100
```

## 六、后续优化方向

### 1. 客户归属和去重优化

目标：

让多张微信截图、多段录音、多个资料自动归到同一个客户档案。

优化内容：

- 根据微信昵称归档
- 根据手机号归档
- 根据截图文件来源归档
- 根据客户名称相似度归档
- 支持人工合并客户
- 支持客户去重提醒

价值：

避免同一个客户生成多个档案，让老板看到更准确的客户池。

### 2. 微信聊天解析增强

目标：

让系统更懂微信聊天截图。

优化内容：

- 区分销售说的话和客户说的话
- 过滤“通过好友验证”等系统提示
- 过滤文件发送、时间戳、表情干扰
- 提取客户昵称
- 提取客户真实问题
- 对长截图做上下文合并

价值：

提高 AI 判断准确率，减少无关内容影响销售意向评分。

### 3. 销售跟进闭环

目标：

不仅告诉销售“该跟谁”，还要记录“有没有跟、跟完结果如何”。

优化内容：

- 跟进任务状态：待跟进、已跟进、已成交、无效
- 跟进提醒
- 超时未跟进提醒
- 跟进结果记录
- 下一次跟进时间
- 成交概率变化

价值：

让老板看到销售执行情况，而不只是看到线索。

### 4. 老板驾驶舱

目标：

给管理层一个更直接的销售管理看板。

优化内容：

- 今日新增线索
- 今日高意向客户
- 今日待跟进客户
- 每个销售上传资料数
- 每个销售高意向客户数
- 未跟进客户提醒
- 成交预测排行
- 销售漏斗

价值：

老板可以一眼判断销售团队今天的线索质量和跟进压力。

### 5. 销售账号和权限体系

目标：

支持多人销售团队正式使用。

优化内容：

- 每个销售独立账号
- 每个销售只能看自己的客户
- 管理员可查看全部
- 主管可查看指定团队
- 上传资料绑定销售
- 手机设备绑定销售账号

价值：

解决真实团队协作和数据权限问题。

### 6. 云端部署

目标：

让老板和销售不用依赖一台本地电脑，任何地方都能访问。

优化内容：

- 部署到云服务器
- 配置域名
- 配置 HTTPS
- 数据库从 SQLite 升级到 PostgreSQL 或 MySQL
- 上传文件持久化存储
- 自动备份
- 日志监控

价值：

从本地 MVP 变成可长期使用的正式系统。

### 7. 手机端体验优化

目标：

让销售在手机上也能快速查看今日跟进任务。

优化内容：

- 移动端首页
- 今日跟进列表
- 一键拨号
- 客户详情
- 跟进状态更新
- 上传截图入口

价值：

销售不用一直坐在电脑前，也能按 AI 建议推进客户。

## 八、老板汇报时可以这样说

### 简短版

我们现在已经做出一个销售 AI 线索工作台，核心链路已经跑通。销售只要正常微信沟通、电话沟通，把微信长截图和通话录音同步进系统，AI 会自动识别内容、判断客户意向、生成客户档案和跟进建议。老板可以在首页看到今天应该优先跟进哪些客户，销售也可以按系统建议去跟进，减少漏单和人工整理成本。

### 详细版

这个项目不是单纯做一个上传文件的系统，而是把销售日常产生的微信截图、电话录音和客户资料变成可管理的销售线索。系统会自动完成 OCR、语音转写、DeepSeek 意向分析和客户归档，最终输出老板能看的线索看板和销售能用的跟进建议。目前本地全流程已经跑通，下一步建议重点优化客户去重、销售跟进闭环和老板驾驶舱，然后再部署到云端，变成团队可以长期使用的销售管理工具。

### 价值表达

项目价值主要有三点：

1. 降低销售整理客户资料的时间成本。
2. 帮老板及时发现高意向客户和漏跟进客户。
3. 用 AI 把销售聊天、录音转化为可跟进、可管理、可复盘的线索资产。

## 十、风险和注意事项

1. 涉及客户聊天和通话录音，正式使用前需要确认合规和授权。
2. API Key、数据库、真实客户资料不能上传到公开仓库。
3. 当前 GitHub 仓库已设为私有仓库。
4. 本地测试密码必须在正式环境修改。
5. 正式使用建议配置 HTTPS、备份和访问权限。
6. AI 判断只能作为销售参考，不应完全替代人工判断。
